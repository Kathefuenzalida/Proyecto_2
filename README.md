# Encuesta en JavaScript

Este proyecto es una aplicación de encuestas interactiva hecha en JavaScript. Permite crear encuestas, agregar preguntas con alternativas, capturar respuestas y mostrar los resultados.

## Descripción

El sistema permite a los usuarios:

1. Ingresar un título para la encuesta.
2. Definir el número de preguntas y alternativas.
3. Ingresar el texto de cada pregunta y sus alternativas.
4. Responder las preguntas seleccionando una alternativa.
5. Ver los resultados de la encuesta.

## Funcionalidades

- Validación de que los campos de texto (título de la encuesta, preguntas y alternativas) no estén vacíos.
- Requiere un número mínimo de preguntas (8) para crear la encuesta.
- Permite ingresar el número de alternativas para cada pregunta.
- Muestra los resultados de la encuesta con las respuestas seleccionadas por el usuario.

## Instalación

1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` en tu navegador para empezar a usar la aplicación.
